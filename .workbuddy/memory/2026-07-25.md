## WordSteps 项目初始分析

- 从 GitHub (https://github.com/ChenJJ-DZL/wordsteps.git) 克隆项目到本地
- 完成全面的代码架构分析，产出详细分析报告：`.workbuddy/reports/wordsteps-analysis-report.html`

### 项目概况
- 纯前端 PWA 应用，原生 JS + CSS，无框架
- 9 个词库（Ogden 850 → 托福），约 38K 词条
- localStorage 数据持久化，Service Worker 离线支持
- 艾宾浩斯 SRS 间隔重复引擎（9级间隔：[10分, 1天, 2天, 4天, 7天, 15天, 30天, 60天, 120天]）

### 核心发现
- **优点：** PWA 离线方案成熟、SRS 基础框架正确、增量模式解决重复词问题、词根排序巧妙
- **核心不足（P0）：**
  1. 无每日学习目标控制
  2. SRS 参数静态固化，缺少自适应（建议升级 SM-2）
  3. 无用户激励机制（积分/成就/打卡）
  4. 代码单文件单体，缺乏模块化
  5. 无用户系统/云端同步/付费体系架构

### 推荐路线
- Phase 1（1-2周）：核心改造 — 每日目标 + SM-2 算法 + 打卡日历 + 模块化重构
- Phase 2（2-3周）：体验增强 — 复习排序 + 拼写测试 + 积分系统 + IndexedDB
- Phase 3（3-4周）：体验打磨 — 手势 + 深色模式 + 加载优化
- Phase 4（持续）：商业化 — 后端 API + 用户系统 + 付费体系 + 原生打包

## Phase 1（精简版）实施完成

### SRS 自适应间隔算法改造
**文件修改：app.js**

1. `scheduleReview()` — 从固定级数步进改为乘法自适应：
   - "认识" → interval *= 2（上限120天）
   - "模糊" → interval *= 0.5（最低1天）
   - "不认识" → interval = 10分钟, lapses++

2. `dueWords()` — 复习队列智能排序：
   - 按 overdue 程度 (now - nextReview) / interval 排序
   - lapses 多的词加权优先（易忘词排前面）

3. 数据格式：`intervalIdx` → `interval`(毫秒)，懒迁移函数自动转换旧数据
4. SCHEMA_VER: 1 → 2
